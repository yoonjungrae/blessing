🚪 숫자 길 모험

플랫폼을 달리고 사다리를 올라가며 1 → 2 → 3 숫자를 순서대로 만나요. 숫자를 모두 모으면 아래의 글이 앞에서부터 드러나고 문이 열려요. 틀려도 괜찮아요, 다시 움직이면 돼요.

현재 말
-
□□□
상태
단계: -
번호 잡기: 1
문: 닫힘
조작
← → : 달리기 / ↑ ↓ : 사다리
스페이스: 점프
놀이 설명

자연스럽게 읽기

  • 숫자는 1 → 2 → 3 순서만 먹혀요. 틀려도 아무 일도 일어나지 않아요.
  • 숫자 3개를 모두 모으면 아래 글이 완성되고 문이 열려요.
  • 사다리로 위아래를 오르고, 스페이스로 점프해요.
  • 단어, 단어 조합, 짧은 문장이 자동으로 이어져요. 모두 실제 생활에서 보는 글이에요.
  • 정답을 묻지 않아요. 문이 열리면 다음 장소로 가요.
